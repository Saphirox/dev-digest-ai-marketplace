# summarize-changes

Summarizes recent git changes into a short digest grouped by theme.

## Install

```
/plugin marketplace add Saphirox/dev-digest-ai-marketplace
/plugin install summarize-changes@dev-digest
```

## Components

| Type  | Name                | Purpose                                    |
|-------|---------------------|--------------------------------------------|
| Skill | `summarize-changes` | Builds a digest from git log, diff, status |

## Usage

Ask Claude something like "summarize what changed on this branch" or "draft standup notes from yesterday's commits".
